Sam requested a reconstruction in a context without partner player data, followed by comparison. A fresh agent with no inherited chat read only the supplied PDF for the protocol and later checked public source access. It was explicitly barred from repository CSVs, sampling scripts, reports, README and context files. The root agent already knew project details; the separation applies to the fresh implementation agent, not the root's memory.

`protocol_locked.md` was hashed before public ranking inspection. `deliverable_lock.json` records the frozen source package and time. `sample_football.py` and `collect_public.py` are byte-for-byte copies of the isolated implementation. Do not edit them while claiming the same lock; implement changes in a separately versioned package if necessary.

The PDF specified top 1,000 by NIL and draws of 25 highest-quarter / 50 middle-half / 25 lowest-quarter. It did not specify seed, rank versus value cutoffs, within-quota selection or tie policy. The independent assumptions are explicit in the protocol. Its seed/hash algorithm differs intentionally from unknown partner choices at lock time.

Original denied bytes and full transformed web evidence remain local under ignored `Data/private/replication/independent_blind_package/`; their hashes are recorded here. The full web text is omitted from Git. `STATUS.md` refers to that complete original package when describing raw evidence.

This is a **post-lock same-frame sampling test**, not independent source replication.
